# M2: Measurement Upgrade

Two additions to the instrumentation:
1. A real-versus-null test calibrated on the null controls. It replaces the fixed
   trend rule.
2. A substrate-agnostic dynamics metric, Multi-Scale Path Divergence (MSPD), from
   arXiv:2606.17091.

Every later layer (L0-L5) will be judged with these instruments.

## 1. Null-calibrated real-versus-null test

`tools/activity/calibrated.py`. Statistic: the Theil-Sen slope of component-normalised
median activity, using predecessor + link-bit components, over the second half [H/2, H]
of each horizon H.

**Per-run test**
- The reference distribution is the pooled set of slopes of every null-control
  trajectory, over every window of the same length (starting every 250k steps).
- A null run is tested against the other runs' nulls only (leave-one-out).
- p = (#null windows ≥ s + 1) / (N + 1). Windows overlap, so p is approximate.

**Group test**
- A paired sign-flip permutation test over seeds on slope_real − slope_null. It is
  exact, with 2^n sign patterns.
- Hedges' g of the paired differences is reported as the effect size.

**Runs.** Seed 1 is `rescue_s1`; see [SCALING.md](SCALING.md), section 1. Seeds 2-5 are
the M1 runs. Seed 4 is truncated at its stagnation (6.5M).

| horizon | runs | real slopes (per 1e6 steps) | per-run p (real) | null slopes | max null-window slope | group p | Hedges' g |
|---|---|---|---|---|---|---|---|
| 2M | 5 | 6.3-23.5 | 0.008 (all) | -1.3-0.0 | 2.5 | 0.031 | 1.70 |
| 4M | 5 | 9.1-14.0 | 0.010 (all) | 0.0-0.4 | 1.0 | 0.031 | 4.45 |
| 8M | 3 | 6.1-7.3 | 0.016 (all) | -0.4-0.3 | 0.4 | 0.125 | 4.67 |

**Findings**
- At every horizon, every real run's slope exceeds every null window's slope. Each
  per-run p is therefore the smallest attainable value, 1/(N+1).
- The group p equals the minimum attainable with the available seeds: 1/32 for 5 seeds,
  1/8 for 3. More seeds are needed to get lower p values; the effect sizes are already
  large.
- **Seed-5 null.** At 8M it gives p = 0.022 under leave-one-out, so at α = 0.05 it is
  flagged. Overall, 1 of 15 null tests is flagged, which matches the nominal 5% rate.
  This is the expected false-positive rate of a calibrated test, not a flaw. The null's
  slope (0.3) is about 20 times smaller than the real runs' slopes (6-7). The old fixed
  rule called the same null class 3b with no way to quantify the error rate.

Full tables: [results/m2/calibrated.md](results/m2/calibrated.md).

## 2. Multi-Scale Path Divergence (MSPD)

Akhtyrchenko, Katsnelson and Ustyuzhanin, "Directing Open-Ended Evolution in Artificial
Life via Multi-Scale Path Divergence", arXiv:2606.17091 (v2, Aug 2026).

- The paper's code link is a placeholder, so `tools/mspd/mspd.py` implements the
  estimator from its equations.
- MSPD measures how the heterogeneity of local transition laws is organised across time
  scales.
- A system with no heterogeneity, or with constant heterogeneity, scores 0.

### Implementation (paper equation numbers)
- **Carriers.** World cells. Agents turn over about 28% per cycle, too fast to hold an
  empirical law. Each cell takes one of 17 discrete states: empty, or one of 4 heading
  quadrants × 3 actions (none, reproduce, kill).
- **Window law (Eq. 10).** The law of the transition pair (Z_i(u), Z_i(u+τ)) over a
  window.
- **Divergence.** Jensen-Shannon distance, the paper's choice for discrete substrates.
- **Heterogeneity (Eq. 11/17).** Mean pairwise distance over 64 sampled active cells.
- **Pooled null.** Each carrier is resampled from the window's pooled law (6
  replicates), and the null mean is subtracted.
- **Functional (Eq. 15).** Dyadic block averaging with repetition upsampling, 5 scales,
  w_j = 1.

**Choices the paper leaves open, fixed here:**
- φ(x) = max(x − 2·sd(H0), 0), a significance floor.
- η = 2·median sd(H0), applied per trace entry.

With the paper's fixed η = 1e-3, the functional (a ratio) inflated estimator noise in a
near-zero trace to O(1). The test suite exposes this: homogeneous noise scored 0.48
before the change and 0.002 after.

### Validation on synthetic systems
`tests/test_mspd.py` uses families patterned on the paper's synthetic N0 suite. 256
sites, 2048 steps, window 64, lags 1 and 4.

| family | MSPD |
|---|---|
| static | 0.0000 |
| homogeneous stationary noise | 0.0022 |
| constant heterogeneity (two fixed site classes) | 0.0031 |
| global synchronous switch | 0.0329 |
| heterogeneity switched on several nested time scales | 0.0860 |

**Shuffled-window surrogates are not a valid null for MSPD.**
- The functional rewards fine-scale variation, and shuffling a trace maximises it.
- So the known multi-scale system scores 0.086, while its own shuffled trace scores
  0.157.
- Controls must be matched systems instead, which is what the paper uses (matched random
  parameters).

### Geb results
`tools/mspd/geb_mspd.py` replays each checkpoint for 2048 cycles using the grid mode of
`tools/replay`. Window 64, step 16, lags 1 and 4.

**Evolved versus unevolved (matched control)**

| world | MSPD | mean heterogeneity h | occupancy |
|---|---|---|---|
| unevolved: random genomes, 2000 steps old (seeds 31-35) | 0.0010-0.0015 | 0.17-0.21 | 0.69-0.77 |
| evolved: L20/N20 at 4M-8M (seeds 1, 2, 3, 5) | 0.026-0.036 | 0.010-0.020 | 0.22-0.59 |

- Mann-Whitney U (one-sided, exact): p = 0.008, the minimum attainable for 4 vs 5 runs.
- **Unevolved worlds are more heterogeneous** (h about 10 times higher). Random genomes
  give cells very different but fixed behaviour.
- **Evolved worlds are 20-30 times higher in MSPD.** Their heterogeneity is smaller, but
  it is reorganised over time.
- This is the distinction MSPD is designed to measure: temporally organised
  heterogeneity rather than stationary heterogeneity. It is independent of the
  genetic-activity evidence above, because it is computed from spatial behaviour only.

**Longer horizon.** 32,768 cycles, window 1024, step 256, lags 1 and 16, on seed-1
archives at 0.25, 1, 2, 3 and 4M.
- Evolved: 0.019-0.034. Unevolved (2 seeds): 0.0024-0.0035.
- The unevolved worlds evolve during the 32k replay, so this horizon understates the
  contrast.

**Over evolutionary time.** All 16 seed-1 archives, 0.25M-4M steps.
- MSPD ranges 0.011-0.036. Every value is at least 7 times the highest unevolved value.
- There is no significant trend with time (Spearman ρ = 0.40, p = 0.13).
- MSPD is strongly anti-correlated with occupancy (ρ = −0.80, p = 0.0002). At this
  observation scale it partly tracks the population state.
- **Conclusion.** MSPD separates evolved from unevolved dynamics, but it does not show
  open-ended growth within an evolved run. Geb's open-ended growth is visible in genetic
  component activity (section 1), not in short-horizon spatial dynamics.
- **Coarser states.** Using empty/idle/reproduce/kill instead of the 17 states gives the
  same picture (results/m2/rescue_s1_action.json).

### Use in later layers
MSPD needs only per-carrier state trajectories, so it applies unchanged to L0
(Flow-Lenia tracers, using the continuous variant), L1 (program-soup tape cells) and Geb.
- It will be the cross-layer dynamics metric.
- Genetic component activity stays the evolution metric where genomes exist.
- The paper also proposes MSPD as a search objective. That use is deferred to the L0
  milestone.
